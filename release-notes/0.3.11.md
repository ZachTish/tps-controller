# TPS Controller 0.3.11

This backward-compatible patch keeps Daily Note task reminders aligned with the setting that already owns their schedule inheritance and makes reminder ignore tags entity-local.

## What changed

- Unscheduled tasks in a recognized Daily Note no longer inherit `scheduled`, `start`, or `date` for Controller reminders when GCM's **Inherit Daily Note date for unscheduled tasks** setting is off.
- Explicit inline task dates continue to trigger normally, and non-Daily-Note task inheritance is unchanged.
- Ignore tags on a reminder rule now evaluate note-level tags for note reminders and same-line hashtags for task reminders. A Daily Note tagged `#dailynote` can therefore suppress its own scheduled row without suppressing every child task.
- Controller uses the versioned GCM Daily Notes API v2 policy and retains the previous behavior when that capability is unavailable.

## Compatibility and migration

- Minimum Obsidian version: 1.12.0.
- TPS Global Context Menu 1.25.2 is required for the corrected Daily Note inheritance policy.
- No settings, note schema, or data migration is required.
- Older or unavailable GCM policy APIs retain Controller's historical inheritance behavior.
