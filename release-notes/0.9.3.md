# TPS Controller 0.9.3

## Bounded notification publication

- Selects and exact-deduplicates the earliest publishable Controller reminder occurrences before per-item SHA-256 work.
- Prevents large repeat-until-complete projections from spending minutes hashing thousands of occurrences that cannot fit in the signed 128-item TishOS queue.
- Fixes the observed state where Controller displayed current reminders but never created `.tishos/native-notifications/v1`, leaving TishOS with an empty upcoming queue.
- Preserves Controller-owned rule/filter/template/stop behavior, chronological deterministic output, signed schema 2, per-device credentials, the 60-day horizon, and the 128-item wire bound.
- Adds a 7,002-entry regression that verifies the earliest 128 unique occurrences are signed and published.

## Compatibility and limitations

- Minimum Obsidian version remains 1.12.0.
- TishOS still schedules only its own leading bounded Apple request window from the signed Controller queue.
- This release was validated only in **Obsidian Plugin Test Vault** and is ready for the user's BRAT pull. It was not directly deployed to production.
