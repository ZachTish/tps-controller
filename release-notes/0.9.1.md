# 0.9.1

- Gives every Controller reminder one authenticated series identity shared by its repeat occurrences.
- Lets TishOS preserve a Snooze only while that exact reminder remains in the current Controller-owned schedule.
- Cancels ordinary repeats and user-created Snoozes after completion, disablement, removal, filtering, or another terminal rule outcome.
- Keeps occurrence IDs distinct and exposes no note path, reminder text, rule, or credential in the new identifier.

This paired wire update uses native-notification schedule schema 2 and requires TishOS 0.9.1 for series-aware Snooze retention. It is a backward-compatible Controller patch with no settings or note-data migration and keeps minimum Obsidian compatibility at 1.12.0.
