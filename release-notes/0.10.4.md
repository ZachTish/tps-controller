# 0.10.4

TPS Controller now completes phone-local TishOS pairing when Files and Obsidian preserve different capitalization or canonical Unicode representation for the same independently linked vault display name.

- Pair, command run, native-notification completion, revoke, and reminder-settings handoff accept only bounded names that are equal after NFC normalization and locale-stable lowercasing.
- Signed run, completion, and revoke requests retain TishOS's exact supplied vault spelling so the existing HMAC remains verifiable. Controller publications retain Obsidian's exact active-vault spelling.
- Materially different names, whitespace changes, invalid names, wrong clients, malformed signatures, stale or replayed requests, and unknown fields remain fail closed.
- TishOS 0.10.15 applies the matching rule only when verifying the independently linked local Controller catalog and notification schedule. Existing exact-name clients remain compatible.
- Mac relay is neither enabled nor required. This release adds no settings migration, credential rotation, notification wire change, reminder-rule change, or note-data mutation. Minimum supported Obsidian remains 1.12.0.

Focused route regressions pass across pair, dual publication, command execution, notification-completion routing, and revoke, including canonical-Unicode equality and materially different-vault rejection. All 20 package-declared test files pass with the three preserved historical notification-comparison skips. TypeScript, the standalone production-mode bundle, and BRAT packaging pass. This isolated clone intentionally performed no runtime-vault deployment; the release artifacts were built directly from the tested source.
