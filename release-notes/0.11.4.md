# TPS Controller 0.11.4

Native Markdown calendar records now receive an index-wide title-link repair at the start of every native-record sync. This closes the 0.11.3 gap where an existing companion-linked title was repaired only when that exact occurrence passed the current feed, date-window, and title-filter reconciliation.

The repair runs before external feed processing, so indexed calendar records self-link their current authoritative file even when a calendar is disabled, its feed fails, the occurrence falls outside the forward-looking sync window, or the title matches Controller's exclusion filter. It preserves the readable `eventTitle` label when available, falls back safely to the existing link alias or filename, and leaves TPS identity, occurrence identity, scheduling, and associated-note fields unchanged. Repeated runs are idempotent.

A successful feed now also marks each returned occurrence present before applying the title exclusion filter. Filtered existing records therefore cannot be misclassified as removed and marked missing, archived, or deleted. Result accounting counts each repaired record once when the same occurrence is also processed from its feed.

This is a backward-compatible bug-fix release with no Controller setting, API, or schema migration. Legacy task-line calendar mode is unchanged. Minimum Obsidian remains 1.12.0; native-record mode requires TPS Global Context Menu 1.43.1 or newer.
