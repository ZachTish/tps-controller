# TPS Controller 0.11.0

This backward-compatible minor release makes Controller the authoritative native-record calendar reconciler when the new opt-in storage mode is enabled.

Each occurrence receives one stable `calendar-event` file. Replays are idempotent, reschedules update the same record, cancellations follow the authored policy, and associated-note links respect the existing per-occurrence/per-series strategy. Legacy task-line ingestion remains the default.

Minimum Obsidian: 1.12.0. GCM 1.38.0 or newer is required for native mode.
