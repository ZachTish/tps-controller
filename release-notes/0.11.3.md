# TPS Controller 0.11.3

Native Markdown calendar titles now open the existing readable event record instead of an optional unresolved companion path. Clicking an event title in Daily Agenda or another embedded Base therefore stays on the authoritative `YYYY-MM-DD - Event title.md` record and no longer offers to materialize a `Calendar event--<hash>.md` stub.

Controller derives the self-link from the path returned by GCM, preserving collision suffixes. Existing companion-linked titles migrate on their next successful reconciliation without changing the TPS record ID, calendar occurrence key, or associated-note fields. Empty calendar summaries use `Untitled event`, and special characters in configured record roots are escaped for safe wikilinks. Legacy task-line calendar mode is unchanged.

This is a backward-compatible bug-fix release with no Controller setting or schema migration. Minimum Obsidian remains 1.12.0; native-record mode requires TPS Global Context Menu 1.43.1 or newer.
