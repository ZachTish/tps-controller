# TPS Controller 1.0.1

The reminder delivery-status banner now appears above Rules in Settings → TPS Controller → Reminder rules. The reminders view shows its reminder items or “All caught up!” without the schedule-status banner.

The settings notice retains verified schedule counts and timestamps, pending publication, pairing, disabled delivery, and provider/fallback information. It refreshes from cached status every 30 seconds while Reminder rules is open and after Check Now, with cleanup when the page or settings closes. It is a polite screen-reader status and wraps long device names. Reminder actions, rules, defaults, pairing, and notification delivery are unchanged.

This is a presentation-only patch. Minimum Obsidian remains 1.12.3; there is no settings migration.

Validation on 2026-09-10: all 456 tests in the release's declared test pipeline completed (453 passed, 3 existing skips, zero failures), including nine new focused notice regressions. TypeScript and the mandatory separate production build passed. The final artifacts were deployed to Obsidian Plugin Test Vault, reloaded as 1.0.1, and verified byte-identical with the release files. Attachment sync and core Obsidian Sync remained disabled. Desktop and simulated 390 px phone UI checks confirmed notice placement/wrapping, the empty reminders view without a banner, and timer cleanup. Saved settings were unchanged and temporary UI overrides were restored. Existing rule-action controls still overflow slightly at 390 px; this patch does not alter those controls.

Tested in the test vault and ready for the user's BRAT pull of ZachTish/tps-controller at numeric version 1.0.1. The attachment-sync iPhone/iPad 500 MB and isolated live-GCS acceptance checks documented in 1.0.0 remain pending. This release does not establish that acceptance or install anything in production.
