# TPS Controller 0.1.4

This patch prevents Controller settings from being overwritten by stale in-memory snapshots.

## Changes

- Reloads the newest plugin data before a save and applies only locally changed top-level fields.
- Preserves synchronized changes and unknown newer-release fields.
- Retains rapid change/revert intent, lets a queued newer edit supersede an in-flight failure, and closes the drain-completion acknowledgement race.
- Keeps external-calendar editor references stable and respects explicit false, blank, and empty-list values during legacy migration.

## Compatibility and validation

- Minimum Obsidian: 1.12.0; no manual migration.
- Focused persistence/command tests: 20/20 passed; TypeScript and diff checks passed.
- Full declared suite: 87/87 passed. A separate production-mode build deployed byte-identical artifacts to the isolated test vault.
- Obsidian 1.12.7 was reloaded with **Reload app without saving**; Controller registered normally and its runtime-owned `data.json` hash remained unchanged.
- GitHub Actions standalone builds remain unavailable because this contained layout imports the adjacent shared deployment helper.
