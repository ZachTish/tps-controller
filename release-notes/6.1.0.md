# TPS Controller 6.1.0 — Native settings search

Registers searchable controls and area descriptions with Obsidian's public declarative settings API while retaining the existing task-oriented settings UI and save owners. Searches include inactive destinations and conditional controls. Native search selects the matching directory entry; activating it opens the existing area and focuses the control, without executing actions or changing settings.

- Compatible feature release. Existing minimum Obsidian 1.12.3 remains; native global search requires Obsidian 1.13.0+.
- No persisted schema, default, command, note, private state, outbound operation or enabled-state change.
- Catalog generated from UI source; enumeration performs no vault/body reads, network, hidden UI mounts or saves.
- Desktop test-vault validation and final artifact receipts are recorded externally at `/Users/zachtisherman/.codex/migrations/tps-settings-search-20261023`. Physical phone and production installation are separate acceptance steps.

Validation: 184 passing declared tests; 3 pre-existing optional historical notification baseline comparisons skipped by their existing availability gate. Separate build passed. Reloaded desktop test-vault inspection covered every existing destination, native “archive” matches, keyboard activation and focus. Health’s archived-time mapping opened its selected editor; GCM’s disabled time-tracking control remained disabled and explained its condition. No actions were executed from a search result. All 18 pre-existing settings/private-state and enabled/Sync-state file hashes remained unchanged.

Installed definition enumeration (1,000 repeated calls per plugin) caused zero scans, metadata/body reads, writes, saves or page renders. Native index queries for archive/serving/scheduled/excluded/notification measured 0.8–1.6 ms in this test sample; this is index computation in a visible but unfocused desktop window, not end-to-end UI or phone latency. Existing mobile CSS remains unchanged and its declared regressions pass; narrow physical-device acceptance is unverified.

Final artifact SHA-256 values accompany the public release and the external receipt; the published bundle is the accepted test-vault bundle.
