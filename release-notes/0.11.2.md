# TPS Controller 0.11.2

Native calendar records now use readable `YYYY-MM-DD - Event title.md` filenames while retaining the same stable TPS and calendar-occurrence identity.

Existing `calendar-<opaque-id>.md` records migrate during their next normal reconciliation. Reschedules and title changes rename the same record through GCM, links update through Obsidian, and filename collisions receive a deterministic numeric suffix rather than overwriting another note. Legacy task-line calendar mode is unchanged.

Minimum Obsidian: 1.12.0. Native calendar mode requires TPS Global Context Menu 1.43.1 or newer.
