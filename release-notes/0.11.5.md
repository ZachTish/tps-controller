# TPS Controller 0.11.5

Native TishOS reminders now keep their canonical timezone-bearing event times, semantic event titles, and one path-backed occurrence per calendar event. Controller recognizes native occurrence/UID/title fields when suppressing duplicate external-feed rows and treats the configured cancellation status as terminal throughout reminder projection and overdue evaluation.

Signed schedule publication is now passive. Controller no longer uses an automatic custom-URL callback to foreground TishOS after a reminder series is removed. TishOS reconciles the replacement schedule the next time it is foregrounded or when iOS grants background refresh; explicit pairing and settings actions continue to open the intended app.

This is a backward-compatible local compatibility build with no settings or signed-schedule schema migration. Minimum Obsidian remains 1.12.0. Correct source preservation for native record updates requires the paired GCM 1.44.3 compatibility build.
