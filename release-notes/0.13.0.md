# TPS Controller 0.13.0

## Atomic native calendar records and cancellation-safe reconciliation

Controller now requires the exact TPS Global Context Menu nativeRecords API v6 and stores calendar records with one canonical `tpsId`, GCM-owned `kind`, a plain title, and meaningful business fields only. Normal reconciliation removes legacy calendar identity aliases, self-link titles, duplicate or derived metadata, blank generated fields, and redundant identity tags while preserving user tags and real note relationships.

Feed cancellations are tracked privately by `tpsId`. Controller applies its cancellation status once, never overwrites a later user-completed status, and restores the prior status only when the note still contains the exact Controller-applied value. Durable intent, partial-batch recovery, and reminder/overdue filtering remain safe across interrupted writes and cancellation-label changes.

Existing notification routing is unchanged: Windows, Linux, and Android retain local Obsidian notices when TishOS is selected, while macOS, iPhone, and iPad retain the signed TishOS-native schedule path.

Validation: 154 focused active checks passed with three intentional historical skips; the complete declared suite, supported TypeScript gate, mandatory separate production build, isolated test-vault deployment, reload, and integrated UI verification passed. Raw `tsc --noEmit` without the repository's declared `-skipLibCheck` compatibility flag still reaches the pre-existing `ical.js` declaration override error. Minimum supported Obsidian: 1.12.0.
