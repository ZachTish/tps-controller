# TPS Controller 0.1.2

TPS Controller now follows BRAT and Obsidian's standard three-file plugin install contract without depending on an extra stylesheet at runtime.

## User-visible changes

- Controller settings, cards, and shared list UI styles now load from the standard `styles.css` artifact installed by Obsidian and BRAT.
- Private-repository BRAT installation instructions are documented for `ZachTish/tps-controller`, including least-privilege read-only token guidance and **Latest** release tracking.

## Reliability and compatibility

- The runtime no longer reads or injects `styles-ui.css`, preventing fresh BRAT installs from losing UI rules and preventing updates from retaining a stale extra stylesheet.
- `styles-ui.css` remains available for legacy/local deployment, and a focused regression requires its complete contents to stay mirrored in `styles.css`.
- Release metadata is synchronized at `0.1.2` across the manifest, package, package-lock root records, and `versions.json`.
- Minimum supported Obsidian version: 1.12.0.
- No settings or data migration is required.

## Validation

- Focused BRAT packaging regression: passed 2/2.
- Clean release suite: passed 78/78.
- Required separate production-mode build: passed; the isolated test-vault deployment reported `unchanged` after the suite's build had deployed `main.js`, `manifest.json`, and `styles.css`.
- Final source and isolated test-vault runtime artifacts matched byte-for-byte for `main.js`, `manifest.json`, `styles.css`, and the preserved legacy `styles-ui.css`.
- The isolated test-vault app was reloaded with `Reload app without saving`; Obsidian 1.12.7 reopened the expected vault, showed Controller's `TPS: User` status, and exposed its command-palette entries. Runtime-owned `data.json` remained unchanged across the reload.

## Known limitations

- GitHub Actions builds remain unavailable because the contained source layout imports the shared adjacent `Plugin Development/deploy-runtime.mjs`; this release is prepared for publication from locally validated artifacts.
- Private BRAT installs require a fine-grained GitHub token with read-only **Contents** access to this repository.
