# TPS Controller 0.3.10

TPS Controller `0.3.10` makes reminder task moves consume TPS Global Context Menu's canonical Task API v2 transaction. It removes Controller's divergent task-block mover and preserves Daily Notes as migrated scratchpad records instead of deleting or completing the source task.

## Changes

- Send GCM an exact task reference containing the source path, zero-based line number, original raw line, and title with strict `exact-or-identity` resolution.
- Request `migrate-if-daily-note` so a Daily Note source becomes `[>]` with `[migratedTo:: [[Target]]]` while the authoritative original block is written to the destination.
- Exclude the source note from the destination picker.
- Suppress a migrated root and all nested task content in its retained scratchpad block from reminder discovery.
- Require GCM Task API v2 for reminder moves. Missing/older APIs, stale tasks, failed writes, and partial outcomes fail closed without invoking Controller's former local fallback.

## Compatibility and migration

- TPS Global Context Menu `1.25.0` or newer is required for reminder task moves. Other Controller features keep their existing integration behavior.
- Existing settings and stored Controller data require no migration.
- Minimum supported Obsidian version remains `1.12.0`.
- Existing historical scratchpad rows written as checked tasks with `[completedDate:: null]` are not rewritten automatically.
