# TPS Controller 0.1.5

This patch prevents external-calendar task reconciliation from corrupting a containing note's YAML frontmatter.

## Changes

- Fixes the legacy tag-repair fallback that could append a calendar tag to the preceding `---` frontmatter delimiter when a synced task used a state such as `[-]`.
- Resolves updates, tag changes, cancellation, and deduplication against one real checkbox task below frontmatter and outside fenced examples; malformed frontmatter and ambiguous identities fail closed.
- Uses atomic task-line writes and excludes inline events from file-level orphan archive/delete handling.
- Preserves nested and loose task blocks, headings, whitespace, and existing CR/LF bytes when inserting or updating an event task.
- Supports all one-character checkbox states plus ordered and unordered task prefixes.
- Keeps all-day task schedules date-only without a duration, and consistently honors duration-versus-end-time mode for timed tasks.
- Prevents field-shaped text inside hidden JSON metadata from overriding visible inline task properties.

## Compatibility, migration, and validation

- Minimum Obsidian: 1.12.0; no settings or data migration.
- Existing notes whose delimiter was already corrupted are not rewritten automatically. Restore a line such as `---- #hca` to `---` once; this release prevents the faulty write from recurring.
- Focused identity regressions: 22/22 passed; focused identity plus cancellation checks: 25/25 passed.
- Full declared suite: 104/104 passed. The required separate production-mode build then reported the isolated test runtime unchanged.
- Obsidian 1.12.7 was reloaded with **Reload app without saving** in `Obsidian Plugin Test Vault`; Controller 0.1.5 registered normally, source/runtime artifacts matched byte-for-byte, and runtime-owned `data.json` remained unchanged.
- GitHub Actions standalone builds remain unavailable because this contained layout imports the adjacent shared deployment helper.
