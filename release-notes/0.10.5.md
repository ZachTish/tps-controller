# 0.10.5

TPS Controller now completes the post-approval return to TishOS on iPhone and iPad without relying on a popup-style WebKit navigation.

- Mobile pairing return uses direct same-frame navigation to `tishos://settings?section=command-bridge`, which iOS hands back to the installed TishOS app instead of applying asynchronous popup blocking.
- Controller clears the durable pending-return marker only after the navigation call succeeds. If navigation throws, the marker is restored and the return retries after the next verified publication refresh.
- macOS retains the existing working return behavior.
- Mac relay remains off and unnecessary for this path. This release changes no pairing credential, signed command-catalog or notification-schedule format, reminder rule, settings migration, or note data. Minimum supported Obsidian remains 1.12.0.

The focused 50-check bridge suite includes a regression that injects a failed mobile return, verifies the callback remains pending, and verifies the following refresh performs the callback and clears it. All 20 package-declared test files, TypeScript, the production bundle, and BRAT packaging pass. The exact build was installed into the physical iPhone's active Obsidian vault and copied back byte-for-byte before Obsidian was relaunched.
