# TPS Controller 0.4.1

Released: 2026-08-14

## Reminder ignore-path fix

- Literal folder and subpath ignore patterns now match on path boundaries at any depth. `_archive` therefore suppresses both `_archive/Note.md` and `Markdown/_archive/Note.md`, without suppressing `_archive-old/Note.md`.
- The corrected shared matcher applies to note and inline-task targets in both reminder delivery and the notification sidebar/overdue list. Global and per-rule ignore arrays continue to combine, and wildcard, regex, `path:`, and `name:` pattern forms remain available.
- Saving any global or per-rule ignore filter now invalidates in-flight reminder work, restarts the effective loop, and immediately refreshes open notification views. Results evaluated under an older filter policy are discarded before alert state or notification delivery.

## Compatibility

- Backward-compatible patch release with no settings or note-data migration.
- Minimum supported Obsidian version remains 1.12.0.
- Existing ignore filter values remain valid.
