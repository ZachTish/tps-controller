# TPS Controller 2.5.0

Apple Wallet setup is separate from bank-server pairing. Advanced → Apple Card & Savings → Open Apple Wallet opens TishOS 0.18.1 (151), where Connect and import starts the initial import on the iPhone. New connections need no finance Controller.

Existing connections use Finish setup and import. Controller finishes any active legacy write, saves its retirement locally, then sends the authenticated receipt that lets the phone take over automatically. Lost replies are retryable. The bank service can remain paused, and no Finances backend is needed just to retire the old Wallet writer. Keep the original Controller open for this one-time handoff. Do not downgrade it after retirement.

Mobile settings omit desktop-only hosting/folder editing and retain pairing-code replacement, unpairing and Finances access. The old Wallet enable toggle is retired; enabled legacy importers retain Stop old importer. Other settings and commands are unchanged. This is a minor release for the backward-compatible handoff protocol and setup entry.

Validation: 586 passing tests, three existing opt-in skips, zero failures; focused settings and handoff tests cover interrupted replies, persistence failures, wrong producers, paused service and in-flight writer ordering. TypeScript and production build pass. Reloaded test-vault desktop/mobile-emulated settings, all six destinations, 393 px Wallet panel, bank dialog and focus restoration were inspected. Runtime data and disabled outbound state were preserved. Native TishOS tests separately verify actual synthetic first-import note files; real Apple authorization is a user action.

Requires Obsidian 1.12.3 or newer. The native flow requires TishOS 0.18.1 (151); its TestFlight availability is separate from this plugin release. Tested in Obsidian Plugin Test Vault and ready for the user's BRAT pull. This release does not install into production.
