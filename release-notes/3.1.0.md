# TPS Controller 3.1.0 — Configurable native calendar fields

External-calendar note creation and reconciliation now honor the configured title, status, and start property names. A separate **Calendar event end datetime** property defaults to end; the existing Duration Property remains independent. Cancellation, restoration, rescheduling, missing-event archive decisions, and schedule stamps use the same field snapshot for each sync. The new end key participates in GCM's confirmed property-key migration.

Configured calendar templates may now contain a nonempty YAML list for kind; Controller preserves those authored values and leaves classification policy to GCM. Template tags are copied to created notes as authored, so remove them from the template when tags should be manual. No notes or settings are silently migrated on load.

This is a backward-compatible **minor** version. Minimum Obsidian remains **1.12.3**. Set the desired status spelling and event template in Controller settings before the coordinated TishOS v0.2 note migration.

## Validation

- Full declared suite: **615 passed, three existing skips**; TypeScript and a separate final build passed.
- The versioned build deployed to the named Obsidian Plugin Test Vault; Hot Reload showed the editable Calendar event end datetime field with its default end alongside the independent Duration Property. The installed runtime matches the build and Controller data.json stayed byte-identical. The test vault has no external calendar feeds, so live feed reconciliation was not attempted; configured-key, repeat-sync, cancellation, and list-template behavior were validated with focused tests.
- Physical iPhone behavior and production-vault configuration remain unverified. This public release is the tested BRAT handoff, not evidence of production installation.
