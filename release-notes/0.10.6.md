# 0.10.6

TPS Controller now supports authenticated global snooze from writable TishOS native notifications.

- TishOS can request the existing fixed ten-minute snooze through the same-device Obsidian custom-scheme bridge.
- Controller authenticates `snooze` inside the existing notification-action HMAC envelope, applies the same freshness and replay protections as Complete, re-resolves exactly one current writable projection, and fails closed otherwise.
- Task reminders write the configured inline snooze property; note reminders write the configured frontmatter snooze property. The refreshed Controller projection moves the occurrence to that timestamp, and normal vault sync carries the mutation to other devices.
- Mac relay remains optional and read-only for this workflow. This release changes no pairing credential, signed schedule schema, reminder rule, or settings migration. Minimum supported Obsidian remains 1.12.0.

The focused 51-check bridge suite covers successful snooze, replay rejection, unsupported actions, and current-item resolution. All 20 package-declared test files, TypeScript, the production bundle, and BRAT packaging pass.
