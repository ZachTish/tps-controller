# TPS Controller 0.6.0

Released: 2026-08-15

## Controller-owned Apple notification schedule

- TPS Controller is the sole source of notification eligibility, timing, filters, template text, snooze, repeat, stop, and terminal-state decisions for TishOS native notifications.
- Each explicitly paired TishOS device receives one bounded, signed schedule under .tishos/native-notifications/v1, authenticated with that device's existing command-bridge SecretStorage credential.
- Projection is read-only and role-agnostic. It does not consume Controller alert state, mutate notes, or enable/disable Controller's other delivery routes.
- Relevant vault changes, settings saves, reminder-state changes, and the 60-second bridge poll refresh publication. Semantic no-write behavior and verified stage/backup replacement preserve the prior valid schedule across transient failures.
- Signed revocation removes the schedule and all of its replacement artifacts together with the paired command catalog.

## Remote-device behavior and limits

- An always-on Mac can publish eligible reminders through TishOS's private CloudKit relay before the source Markdown file materializes on an iPhone. The receiving TishOS installation can schedule the verified projected item without rereading that file.
- CloudKit/background execution is best-effort. This release does not add an APNs provider and cannot guarantee immediate delivery for an item created remotely just before its fire time.
- A schedule is capped at 128 items, a 60-day horizon, and 256 KiB per client. It contains bounded rendered notification text, time, opaque digest, and optional safe source Markdown path; it never contains pairing secrets, rule definitions, unrestricted note bodies, or the command catalog.
