# TPS Controller 2.5.2

Connect Apple Wallet is now visible on the default Overview page, before Device role. The same action remains in Advanced. It opens Wallet setup in TishOS 0.18.2 (152), whose home entry is visible even before linking a vault. Setup confirms the destination and Apple accounts, then starts the first import.

This patch changes discoverability only. All six settings destinations, bank-host and pairing controls, request-folder editing and legacy importer recovery remain. No settings migration, permission grant, credentials change or automatic financial read occurs when the page opens.

Validation: 588 passing Controller tests, three existing opt-in skips, zero failures; focused Wallet tests; mandatory separate final build and isolated test-vault deployment/reload. Desktop and mobile-emulated settings visually verified. Runtime data.json was preserved byte-for-byte. Native first import is covered by separate synthetic integration tests; physical Apple account reconciliation remains an iPhone acceptance step.

Minimum Obsidian: 1.12.3. Tested in Obsidian Plugin Test Vault and ready for the user's BRAT pull. Not installed in production. The new native setup requires TishOS 0.18.2 (152); its TestFlight availability is tracked separately.
