# TPS Controller 4.0.1

Calendar feeds that regenerate DTSTAMP no longer rewrite otherwise unchanged event notes. This avoids unnecessary Sync uploads and recurrence dispatch. Actual event changes, SEQUENCE and LAST-MODIFIED revisions still persist; older content cannot undo the last meaningful change.

No settings or note migration is included. Identity keys remain configurable. This patch does not implement cross-device import ownership or a TishOS app handoff.

Validation: 158 focused assertions; full suite 812 passed, three existing optional skips, zero failures. Separate production build deployed to Obsidian Plugin Test Vault. Explicit plugin reload verified 4.0.1. Three installed synthetic-feed refreshes produced zero mutation batches and retained the fixture body. The installed check scoped the record snapshot/path planner because an unrelated malformed archived QA note blocks the full GCM snapshot. Outbound automation remained disabled. Mobile and multi-device acceptance remain unverified.

Minimum Obsidian: 1.12.3. Tested in the test vault and ready for a BRAT pull; this release does not assert production installation.
