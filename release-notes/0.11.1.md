# TPS Controller 0.11.1

This backward-compatible patch keeps native calendar occurrence reconciliation deterministic when GCM stores record identity in a configurable tag rather than fixed ID/schema properties.

Controller consumes GCM `nativeRecords` API v2's canonical inspector and rebuilds its occurrence index after that API is confirmed. GCM v1 property identity remains supported.

Minimum Obsidian: 1.12.0. Tag identity requires GCM 1.43.0 or newer.

## Validation and artifacts

- Validation: the complete declared `npm test` suite, its production build, a separate final `npm run build`, `npx tsc --noEmit --skipLibCheck`, and `git diff --check` passed. The focused native calendar suite passed 5/5.
- Test-vault/POC QA: Controller indexed the tag-identified calendar records after reload. A real force-sync replay retained exactly 85 records for 85 unique occurrence keys, created no duplicate identity, and did not restore the removed ID/schema properties.
