# TPS Controller 3.0.0 — Whole-note calendar and reminder records

External calendar sync now uses one Markdown event note per occurrence. The Calendar storage and per-feed Create as/Task destination controls are removed. New installations default to native event records. A vault with an explicitly saved legacy calendar mode pauses sync and offers **Use whole-note events** in Calendar rules; it does not silently run the old inline writer. Review existing items before activating note sync, because unmatched feed occurrences can create event notes. Existing task lines are left unchanged.

Reminders use note frontmatter and external events. The Inline task reminders selector is removed, saved inline modes normalize to notes-only, and old task-line notification actions cannot mutate the containing note. Per-feed note folders, templates, reschedule actions, note reminders, and explicit read-only quarantine review remain. No automatic note conversion, repair, or vault scan was added.

Global and per-rule checkbox-state reminder filters are removed from settings. Saved checkbox filters no longer suppress whole-note reminders and are cleared on the next settings save; note status, path, tag, and time filters remain available.

This is a breaking data/settings behavior change, so the version advances to 3.0.0. Minimum Obsidian: **1.12.3**. A matching current GCM native-record installation is needed for Controller's event-note sync. Historical inline records remain available as Markdown but are no longer synchronized or actioned by Controller. Physical iPhone behavior has not been verified in the Test vault.

Validation: 613 declared checks, 610 passed, 3 pre-existing optional skips; TypeScript and a separate production build passed. Installed Calendar rules showed no storage-mode or per-feed task-output choice; installed Reminder rules showed no inline-task selector or checkbox-state filters. The Test vault has no external calendar feeds, so a live provider sync was not exercised.
