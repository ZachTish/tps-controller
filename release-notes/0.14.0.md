# TPS Controller 0.14.0

## Intent

Protect user-designated template notes from Controller's background automation while keeping instantiated Daily Notes and calendar notes free of the template identity marker.

## User-visible changes

- Background calendar sync, sync-conflict cleanup, scheduled two-stage archive, and automatic S3 attachment work now honor TPS Global Context Menu's `templates` API v1. A protected note is skipped instead of having its status, frontmatter, task lines, body, path, or attachment sources changed.
- Controller rechecks live authority at mutation boundaries, including native calendar batches, conflict/archive renames, automatic note rewrites, and attachment archive requests. Compatible API rejections and errors fail closed.
- Explicit manual two-stage archive and S3 upload commands keep their existing user-directed behavior. Older or unavailable GCM template APIs keep the established Controller behavior for cross-device compatibility.
- Controller-owned Daily Note fallback and external-event note creation remove the configured template marker before variable expansion and again after Templater. Rejected source aborts processing, and create-race winners are not treated as Controller-owned instances.
- The TishOS command-bridge confirmation modal now uses the shared keyboard-aware mobile overlay contract.

## Compatibility and migration

- Minimum supported Obsidian version: 1.12.0.
- This is a backward-compatible feature release with no Controller setting migration and no new note/frontmatter property.
- Template protection requires a compatible TPS Global Context Menu `templates` API v1. Devices with an older GCM keep Controller's previous behavior until GCM is updated.

## Validation

- Focused tests cover GCM API compatibility/failure semantics, standalone Daily Note and external-event instance preparation, post-Templater cleanup, create-race ownership, calendar task/native-record mutation boundaries, conflict and two-stage archive renames, automatic/manual S3 behavior, and the cross-plugin mobile modal contract.
- The complete 23-file release suite, TypeScript no-emit validation, diff checks, and mandatory separate production-mode build passed. Obsidian 1.13.7 reloaded the isolated test vault with Controller 0.14.0 beside GCM 1.50.0. Outbound calendar, notification, and attachment automation remained disabled; no live endpoint was invoked. Production was not accessed. This release is ready for a BRAT pull after publication.

## Known limitations

- Protection applies only when GCM exposes the compatible v1 API; this preserves operation on mixed-version devices but means older GCM builds cannot protect tagged templates from Controller automation.
- Automatic S3 uploads already completed before a last-moment mutation-boundary rejection may remain in the configured bucket, but Controller will not rewrite the protected note or archive its local attachment sources.
