# 2.6.0 — Connections in one place

- Added Connections with Banks & Wallet, AI, TishOS devices and Food databases. Calendar feeds and Attachment sync remain one click away in their existing workflow pages.
- Bank setup is grouped beside connect/sync/reconnect/disconnect, pending sign-ins, history depth and the Apple Wallet setup action. Setup changes refresh the bank controls immediately; paired clients do not receive host credential editors.
- Moved TishOS pairing/catalog controls out of Overview. Removed circular links and obsolete bank controls from Advanced.
- Added a versioned, disposable connection-editor contract; missing/older plugins show an actionable update message. Detached editors cannot overwrite a later selection after asynchronous operations finish.
- Audited all eight active TPS plugins in v0.2. CONNECTIONS.md records ownership and legacy candidates that need separate migration work before removal.

## Compatibility and state

This minor release adds connection settings ownership/API support without changing note schemas or requiring a settings migration. Minimum Obsidian: **1.12.3**. Install **Controller 2.6.0 first**, then **Finances 1.9.0**, **Health 3.4.0**, and **AI Gateway 0.10.0** through BRAT. Controller requires Obsidian 1.12.3 on each device.

Controller owns visible connection navigation and lifecycle; each domain plugin supplies its existing editor and validated saves/operations through `api.connectionSettings = { version: 1, render(parent): dispose }`. This does not duplicate or relocate provider execution, credentials, pairing authority, tokens, cursors, requests or note mappings. Navigation state is transient. Existing commands and service APIs remain. Bank/AI configuration and actual secret values remain device-local; Health's USDA reference names remain shared vault settings.

Apple Wallet permission, vault/account selection and initial import happen in TishOS on the iPhone. The existing native Wallet setup requires TishOS 0.18.2 (152) or newer. This release does not change native authorization, start a connection, grant permission, or enable background automation merely by opening settings.
