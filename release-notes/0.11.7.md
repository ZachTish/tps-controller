# TPS Controller 0.11.7

Bounded TishOS schedules now favor live reminder coverage before repeat depth. Every exact reminder series with a currently due occurrence receives one candidate before extra occurrences from an earlier series can consume the 128-item transport lease. Further occurrences are selected round by round across those live series, and any remaining capacity follows the existing chronological candidate order.

The published result is still sorted by canonical fire time and raw UTF-8 occurrence identifier. Controller changes no intended fire time, occurrence or series digest, reminder rule, completion/Snooze authority, pairing credential, or signed-schedule schema. If more than 128 exact series are live at once, the existing deterministic bound still applies.

This is a backward-compatible selection fix with no setting, note-data, or migration change. Minimum supported Obsidian remains 1.12.0.
