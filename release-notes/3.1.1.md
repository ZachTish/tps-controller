# TPS Controller 3.1.1 — Native Mac refresh invalidation

Local candidate based on production-matching 3.1.0 (`cb068db`). Existing
whole-note calendar/reminder behavior and configured fields remain unchanged.

The optional macOS-only sender signals the currently paired native TishOS app
after a complete signed publication drain. It sends only authenticated
invalidation metadata to fixed IPv4 loopback, never note contents, paths or
caller-selected cloud scope. A signed 202 receipt acknowledges queue admission
only. Failed delivery does not reject Controller publication or launch an app.
Current terminal pairing generation, lifecycle and revocation are rechecked.

The publication drain coalesces concurrent completion/deletion requests into
serial passes and clears ownership in the same turn as its last dirty check.
