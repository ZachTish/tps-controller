# TPS Controller 0.8.1

Released: 2026-08-17

## Native reminder parity

- Publishes a file-reminder occurrence while it is still visible as currently due in Controller's bounded reminder window instead of dropping it at the strict future-time boundary.
- Preserves the occurrence's original fire time and stable digest, allowing TishOS to deliver it once without manufacturing a different identity on every refresh.
- Advances an older repeat-until-complete reminder to its deterministic next configured repeat when the current paired device has no Controller delivery state, while honoring maximum repeats and trigger-base end policy.
- Keeps external-event catch-up future-only and preserves Controller as the sole reminder-rule authority. No Base view, TishOS lead time, rule mutation, alert-state consumption, or note mutation is added.

## Compatibility

- Requires TishOS 0.8.1 for bounded late-occurrence acceptance and once-only operating-system handoff.
- Adds no Controller setting, persisted-rule migration, or note-data migration.
- Minimum supported Obsidian remains 1.12.0.
