# TPS Controller 0.2.0

This minor release consolidates Controller settings into clear destinations while keeping detailed rules close to the actions that manage them.

## User-visible changes

- Adds five shallow destinations: Overview, Calendar rules, Reminder rules, Automations, and Advanced.
- Shows concise calendar-source/output summaries and one selected feed editor instead of expanding every feed.
- Keeps reminder rules, defaults, filters, snooze choices, and maintenance available even while reminder evaluation is disabled.
- Splits Automations into direct Archive files and Upload attachments selectors so only one workflow editor is visible at a time.
- Restores keyboard focus after route and conditional-field rerenders and uses a compact horizontal hub on mobile.

## Compatibility and migration

- Minimum supported Obsidian version: 1.12.0. Desktop and mobile are supported.
- Existing setting keys, defaults, secrets, and actions are unchanged; no settings migration is required.
- Calendar source editing still uses one selected editor, and the detailed S3 workflow remains intentionally contained on its own automation page.
- GitHub Actions standalone builds remain unavailable because this contained layout imports the adjacent shared deployment helper.
