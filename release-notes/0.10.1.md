# 0.10.1

TPS Controller now associates synced calendar tasks with the correct existing local note instead of always retaining an unresolved generated placeholder.

- A unique exact event-title match is reused from either the note basename or its authored `title` property.
- Series-wide note mode accepts the unique match directly. Per-occurrence mode requires the note's `scheduled` value or vault path to match that occurrence day.
- The task's visible wikilink and hidden `associatedNotePath` are committed from one resolved path, so Calendar Base recognizes and opens the existing note.
- Explicit/custom task-note associations survive later calendar reconciliation. A reschedule replaces only Controller's own stale day-scoped placeholder.
- Duplicate eligible titles fail closed to Controller's deterministic source/UID/day target; no ambiguous note is selected.
- Resolution uses one cached title index per sync rather than scanning the vault separately for every calendar event.

This is a backward-compatible bug-fix release. It adds no setting or data migration, does not bulk-rewrite tasks, and keeps minimum Obsidian compatibility at 1.12.0. Existing tasks adopt the corrected association on their next safe event reconciliation.
